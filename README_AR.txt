منشئ ومحرر السور V14.2

تم تصحيح نظام الترقيم بالكامل:

البسملة:
n = 0
مثال سورة 110: 110000.mp3

الآية الأولى بعد البسملة:
n = 1
110001.mp3

الآية الثانية:
n = 2
110002.mp3

وهكذا.

التصحيح يشمل:
- العناوين الظاهرة في المنشئ.
- n داخل ملف JSON.
- أسماء ملفات الصوت.
- إضافة البسملة للملفات القديمة.
- إعادة ترقيم الملفات القديمة عند فتحها.
- فحص صحة أسماء ملفات الصوت قبل التصدير.
- عرض أسماء ملفات mp3 من اليسار لليمين لتجنب ظهورها معكوسة بصريًا في واجهة RTL.

استبدل فقط منشئ السور القديم بهذا الملف.
لا حاجة لتغيير ملفات الموقع الحالية.
