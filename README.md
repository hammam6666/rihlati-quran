# رحلتي مع القرآن — V11 (سورة الإخلاص)

هذه النسخة تختبر سهولة إضافة سورة جديدة بعد الانتقال إلى ملفات JSON مستقلة.

## ما تم
- إضافة `data/surahs/112-al-ikhlas.json`.
- فتح بطاقة سورة الإخلاص في `data/index.json`.
- إضافة بيانات:
  - الآيات الأربع
  - أفهم
  - أطابق
  - أتدرب
  - أختبر نفسي
- محطتا أستمع/أردد ومحطة أرتب تعمل تلقائيًا من بيانات الآيات نفسها.
- التقدم والنجوم والاختبار والشهادة مستقلة لسورة الإخلاص.
- تحديث `generated-bundle.js` للتشغيل المحلي بدون Python أو خادم.

## اختبار المحرك
1. افتح سورة الإخلاص.
2. جرّب الاستماع.
3. جرّب «أفهم» و«أطابق».
4. أكمل محطة وسجّل تقدمًا.
5. انتقل إلى الناس أو الفلق.
6. عد إلى الإخلاص وتأكد أن تقدمها محفوظ بشكل مستقل.
